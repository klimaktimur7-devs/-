# ИИ-продавец сайтов «Байт & Борщ»

Голосовой ИИ-ассистент, который звонит потенциальному клиенту и предлагает сделать сайт.
Говорит по-украински и переходит на русский, если собеседник говорит по-русски.
Выясняет, чем занимается бизнес, подбирает пакет из прайса, отвечает на возражения
и договаривается о бесплатной консультации. После звонка сохраняет итог.

Пока это **тестовая версия без телефонного номера**: ты говоришь с ботом голосом в браузере
и играешь роль клиента. Телефонию подключим потом.

## Что внутри

| Файл | Что это |
|---|---|
| `config.yaml` | Название студии, имя бота, прайс, цель звонка — **меняй здесь** |
| `prompt.py` | Сценарий разговора и правила для бота |
| `server.py` | Сервер: разговор, итог звонка, стоп-лист |
| `llm.py` | Подключение к нейросети (Gemini / Groq / OpenRouter / Claude) |
| `static/index.html` | Страница для теста: микрофон → бот → голос |
| `calls/` | Итоги звонков в JSON (создаётся сама) |
| `do_not_call.txt` | Стоп-лист: номера, куда больше звонить нельзя (заполняется сам) |

## Запуск (бесплатно, через Gemini)

1. Нужен Python 3.10+.
2. Получи **бесплатный** ключ Gemini: https://aistudio.google.com/apikey (нужен только Google-аккаунт, без карты).
3. Установка и запуск:
   ```bash
   cd sales_bot
   pip install -r requirements.txt
   export GEMINI_API_KEY="твой-ключ"     # Windows: set GEMINI_API_KEY=твой-ключ
   uvicorn server:app --port 8000
   ```
4. Открой http://localhost:8000 в **Chrome или Edge**, разреши микрофон.
5. Заполни поля о клиенте (необязательно), нажми «Начать звонок» и отвечай голосом или текстом.
6. «Положить трубку» — бот составит итог: результат, что нужно клиенту, какой пакет, следующий шаг.

### Другие нейросети

Меняется одной строкой `provider:` в `config.yaml`:

| provider | Цена | Ключ | Переменная |
|---|---|---|---|
| `gemini` | бесплатно (лимит в день) | aistudio.google.com/apikey | `GEMINI_API_KEY` |
| `groq` | бесплатно (лимит), очень быстро | console.groq.com/keys | `GROQ_API_KEY` |
| `openrouter` | бесплатные модели `:free` | openrouter.ai/keys | `OPENROUTER_API_KEY` |
| `claude` | платно, лучшее качество | console.anthropic.com | `ANTHROPIC_API_KEY` |

Бесплатные лимиты у сервисов время от времени меняются — если модель перестала работать,
проверь её актуальное название на сайте сервиса и поправь `model` в `config.yaml`.

Голос бота — встроенный в браузер. Лучше всего украинский звучит в **Edge**
(там есть нейроголоса uk-UA). В Chrome украинского голоса может не быть — тогда включай русский.

## Настройка

- **Прайс и пакеты** — `config.yaml` → `pricing`. Бот называет только эти цены.
- **Скорость и ум** — `effort: low` (быстро, для голоса) / `medium` / `high` (умнее, но дольше пауза).
- **Сценарий, возражения, тон** — `prompt.py`.

## Правила, которые зашиты в бота

- В первой же фразе говорит, что он ИИ-ассистент, и от какой студии звонит.
- Если человек просит не звонить, бот вежливо прощается, а номер попадает в `do_not_call.txt`.
  На номер из стоп-листа звонок не начнётся.
- Не выдумывает цены, не просит платёжные данные по телефону.
