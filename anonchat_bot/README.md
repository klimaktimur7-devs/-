# anonchat_bot

Скрипт для твоих Telegram-аккаунтов (session-файлы Telethon). Для каждого аккаунта он:

1. пишет `/start` боту @N1anonchat_bot и нажимает «Поиск собеседника»;
2. проходит спонсоров: нажимает Start в ботах, подписывается на каналы или отправляет заявку на вступление, открывает Mini App и находит в ней ссылку на канал;
3. нажимает «Проверить подписку»;
4. пишет в лог, засчиталось или нет, и какие спонсоры не засчитаны.

Капчу скрипт не решает. Если бот её показал, аккаунт получает статус `captcha` и пропускается.

## Быстрый запуск на Windows (двойным кликом)

Сначала один раз установи Python с https://www.python.org/downloads/ и при установке поставь галочку **Add Python to PATH**. Потом запускай файлы из папки по порядку:

| Файл | Когда | Что делает |
|---|---|---|
| `1_setup.bat` | один раз | ставит библиотеки и открывает `.env`: впиши `API_ID` и `API_HASH` с my.telegram.org |
| `2_add_account.bat` | на каждый аккаунт | вход в Telegram: имя, номер, код, пароль 2FA |
| `3_check_buttons.bat` | один раз, для проверки | показывает спонсоров и кнопки, ничего не нажимает |
| `4_run.bat` | каждый раз | прогоняет все аккаунты, итог в окне и в папке `logs` |

Если у тебя уже есть `.session`-файлы, положи их в папку `sessions` и пропусти шаг 2.

## Установка вручную (Windows)

1. Установи Python 3.10 или новее с https://www.python.org/downloads/. При установке поставь галочку **Add Python to PATH**.
2. Распакуй папку `anonchat_bot`, открой её в проводнике, в адресной строке набери `cmd` и нажми Enter.
3. Выполни:
   ```bat
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   copy .env.example .env
   ```
4. Открой `.env` в Блокноте и впиши `API_ID` и `API_HASH`. Их выдают на https://my.telegram.org → API development tools.

Каждый раз, когда открываешь новое окно cmd, сначала активируй окружение командой `.venv\Scripts\activate`.

## Сессии

У тебя уже есть `.session`-файлы Telethon? Положи их в папку `sessions\`.

Если нет, создай для каждого аккаунта отдельно:
```bat
python login.py acc1
```
Скрипт спросит номер телефона, код из Telegram и пароль 2FA, если он включён. Файл появится в `sessions\acc1.session`.

## Запуск

**Сначала один раз запусти dry-run.** Скрипт дойдёт до списка спонсоров, покажет все кнопки (текст, тип, ссылку) и ничего не нажмёт:
```bat
python main.py --dry-run --session acc1
```
Проверь в выводе две вещи:
- нашлась кнопка проверки подписки. Если нет, поправь `CHECK_BUTTON_REGEX` в `.env`;
- если кнопку «Поиск собеседника» не нашло, поправь `SEARCH_BUTTON_REGEX` и `SEARCH_FALLBACK_TEXT` (скопируй точный текст кнопки из вывода).

Потом настоящий прогон:
```bat
python main.py --session acc1      :: один аккаунт
python main.py                     :: все сессии из папки sessions по очереди
```

## Linux

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # заполнить
python main.py --dry-run --session acc1
python main.py
```
Запуск в фоне: `nohup python main.py > run.out 2>&1 &`. Расписание: строка в cron вида `0 */6 * * * cd /path/anonchat_bot && .venv/bin/python main.py`.

## Что получается на выходе

- `logs\run_ДАТА.log`: каждый шаг и итог по каждому аккаунту:
  ```
  [acc1] Спонсоры:
    1. @sponsorbot1   бот             старт нажат         ✅
    3. t.me/+abc...   канал (инвайт)  заявка отправлена   ✅
    5. https://...    mini app        ссылка не найдена   ❌
  [acc1] Проверка подписки: раунд 1 → FAIL (не засчитаны: #5)
  [acc1] ИТОГ: ❌ НЕ ПРОЙДЕНО (fail) — причина: ...
  ```
- В конце печатается сводная таблица по всем аккаунтам.
- `logs\summary_ДАТА.json`: то же самое в машиночитаемом виде.

Статусы аккаунта: `ok` (пройдено), `fail` (бот не засчитал подписку), `unknown` (ответ бота не распознан), `captcha`, `flood` (Telegram попросил ждать дольше `FLOOD_MAX_WAIT`), `failed` (ошибка или таймаут после повторов), `unauthorized` (сессия не авторизована или слетела).

## Если спонсор Mini App не проходится

Скрипт открывает страницу Mini App без браузера и ищет в ней ссылку на канал или бота. Если ссылка появляется только после нажатия кнопки на странице или подгружается позже скриптом, найти её так не получится. Тогда в логе будет «ссылка не найдена», а рядом адрес страницы и начало её HTML. Пришли этот кусок лога, и я допишу обработку под этот Mini App.

## Настройки (`.env`)

Все параметры с пояснениями есть в `.env.example`: регулярки текстов бота, таймауты, паузы между действиями и аккаунтами, лимит FloodWait и прокси (один на все аккаунты, формат `socks5://user:pass@host:port`).
