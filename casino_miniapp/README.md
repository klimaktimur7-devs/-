# Glint Mini App

Прототип игрового Telegram Mini App на дизайн-системе Glint. Всё приложение — один файл `index.html`: React 18 грузится с cdnjs, стили и компоненты встроены.

Разделы: PvP (лобби и раунд со ставками), Магазин (гифты, фильтры, покупка в инвентарь), Solo (лобби игр), Профиль (баланс и инвентарь).

Работает только на демо-монетах. Баланс, ставки и выбор победителя считаются в браузере, поэтому для реальных денег нужен сервер.

## Запуск локально

```bash
cd casino_miniapp
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Подключение к Telegram

1. Выложите `index.html` на любой HTTPS-хостинг (GitHub Pages, Vercel, Netlify).
2. В @BotFather: `/newapp` (или `/mybots` → Bot Settings → Menu Button) и укажите URL страницы.
3. Внутри Telegram страница вызывает `Telegram.WebApp.ready()` и `expand()`, красит шапку в цвет фона и берёт ник из `initDataUnsafe.user`.

## Что нужно для настоящей версии

- Бэкенд: баланс, приём ставок, выбор победителя и проверяемая честность (provably fair). Клиенту нельзя доверять суммы.
- Проверка подписи `initData` на сервере, иначе ник и id пользователя можно подделать.
- Пополнение через TON Connect / Telegram Stars.
- Лицензия на азартные игры в юрисдикциях, где вы работаете.
